# YOURS Finland

Public site for the Finnish chapter of the Young Researchers Society.

Dr. Mohamed Noureldin (Dr. Nour) is the country lead. The other team cards are open seats, marked as placeholders. The first-season events are plans, not confirmed dates.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
```

## Contact

The join form opens an email to the country lead at the address published on his [Aalto profile](https://www.aalto.fi/en/people/mohamed-noureldin). The site does not store submissions.

Chapter copy lives in `lib/content.ts`. Set `NEXT_PUBLIC_SITE_URL` to the public domain before deploy so canonical links and the sitemap use it.
